A 4 KB chess engine in a single Python file: 0x88 board, negamax with alpha-beta, transposition table, iterative deepening, PVS, quiescence search, late-move reductions, futility pruning and check extensions, with a material, piece-square, pawn-structure and king-safety evaluation. It searches a fixed 90,000 nodes per move, so every game is deterministic, and plays through the make.fun environment protocol.

## Run it

```sh
python3 -P -s main.py
```
